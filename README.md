## Sobre a disciplina

Cálculo Numérico estuda como resolver problemas matemáticos usando o computador de forma **precisa, eficiente e confiável**. Em vez de soluções analíticas exatas (que muitas vezes não existem), trabalhamos com aproximações controladas — e aprendemos a medir e comunicar o erro dessas aproximações.

Os grandes temas da disciplina são:

- **Erros numéricos** — como surgem, como se medem (absoluto, relativo, percentual) e como se propagam nos cálculos
- **Representação de números no computador** — ponto flutuante, precisão finita, arredondamento e truncamento
- **Sistemas de equações lineares** — métodos diretos e iterativos para resolver Ax = b
- **Interpolação e aproximação de funções** — construir uma função a partir de pontos dados
- **Ajuste de curvas** — mínimos quadrados e regressão
- **Derivação numérica** — diferenças finitas e erro de truncamento
- **Integração numérica** — quadratura, trapézio, Simpson
- **Zeros de funções** — bissecção, Newton-Raphson e outros métodos iterativos
- **Equações diferenciais ordinárias** — métodos de passo único e passo múltiplo
